# Contributing

To propose an agent, open an issue with the task and the public dataset you would evaluate on. We review proposals against the criteria in [README.md](README.md#how-agents-are-added): pre-registration, paired held-out comparison with intervals, a public benchmark, exact model ids and spend with archived outputs and a rerun path, named human acceptance, an expiry date, and real failures shown.

Bug reports and corrections to an existing agent are welcome as issues or pull requests. Do not include secrets, credentials or private data.
